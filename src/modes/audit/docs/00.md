### Phase 0. Audit context and baselines

Purpose: make results comparable and debuggable.

* Host identity: hostname, OS, kernel, init, desktop, GPU, storage, uptime, last boot ID
* Time reference: boot ID, boot timestamp, timezone
* Log scope: "current boot only" vs "since install"
* Persistent journal status (important if you want "since boot time" to be reliable after crashes)

**Test Cases:**
1. Hostname detection (hostnamectl/hostname)
2. OS information (/etc/os-release)
3. Kernel version and architecture
4. Init system (systemd version)
5. Desktop environment (XDG_CURRENT_DESKTOP)
6. GPU detection (lspci)
7. Storage devices (lsblk)
8. Boot ID (journalctl --list-boots)
9. Boot timestamp (systemd-analyze)
10. System uptime
11. Timezone (timedatectl)
12. Journal status and persistence (/var/log/journal)
13. Journal disk usage (journalctl --disk-usage)
14. Reboot required marker (/var/run/reboot-required)
