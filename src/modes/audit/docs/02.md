### Phase 2. Kernel early boot and hardware bring-up

Purpose: hardware errors before userspace hides them.

* Kernel ring buffer: **hardware errors first**

  * Machine Check / AER / PCIe / NVMe / IOMMU faults
  * Firmware bugs, ACPI table issues
* Kernel module load failures, driver init failures
* GPU driver init (even if later you also check compositor)
* Kernel taint status (/proc/sys/kernel/tainted)
* udev rules verification and journal errors

**Test Cases:**
1. Hardware errors (MCE, AER, PCIe, NVMe, IOMMU)
2. Kernel errors (dmesg error level)
3. Kernel warnings (dmesg warning level)
4. Kernel module load failures
5. GPU driver initialization issues
6. ACPI/Firmware errors
7. Kernel taint status (non-zero indicates unsupported modules or hardware issues)
8. udev rules verification (udevadm verify /etc/udev/rules.d)
9. udev journal errors
