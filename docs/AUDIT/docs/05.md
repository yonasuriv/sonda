### Phase 5. Storage and filesystem health (post-mount)

Purpose: your "141 filesystem/disk errors" belongs here, not late.

* Journal-detected I/O errors (blk_update_request, nvme timeouts)
* Filesystem errors (EXT4/BTRFS/XFS), read-only remounts, corruption signals
* SMART/NVMe health summary (health OK does not contradict filesystem errors, it just means the drive isn't reporting imminent failure)
* Disk usage monitoring (filesystems >= 90% full)

**Test Cases:**
1. I/O errors (blk_update_request, nvme timeouts, disk timeouts)
2. Filesystem errors (EXT4/BTRFS/XFS errors, failures, corruption warnings)
3. Disk health (SMART/NVMe status via smartctl)
4. Disk usage (filesystems >= 90% full - warns about potential space issues)
5. Current read-only mounts (findmnt - detects currently mounted read-only filesystems)
