### Phase 9. User session services and desktop environment stability

Purpose: after login reliability.

* user@UID systemd instance failures
* GNOME Shell extensions status and crashes
* Portal services (xdg-desktop-portal), keyring issues, dbus failures

**Test Cases:**
1. Failed user session services (systemctl --user --failed)
2. Desktop environment crashes (segfault, SIGSEGV, SIGABRT)
3. GNOME Shell extension status (total and enabled count via gnome-extensions)
4. GNOME Shell extension crashes (journal grep)
5. Portal service issues (xdg-desktop-portal errors/failures/crashes)
6. Keyring errors (unlock failures, errors)
7. DBus failures (rejected messages, errors)
