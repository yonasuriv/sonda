### Phase 11. Current system posture snapshot

Purpose: "right now" state, separate from boot timeline.

* CPU/RAM/disk usage, load average
* Top offenders (process RSS, IO wait)
* Open crashed coredumps summary
* Package manager integrity (dpkg, apt, snap, flatpak)
* If the system has a restore file/backup available

**Test Cases:**
1. Current CPU usage snapshot (top processes)
2. Current memory status (free -h)
3. Available coredumps (coredumpctl list)
4. System health state (systemctl is-system-running)
5. Active network connections (ss -tun)
6. dpkg audit (dpkg --audit)
7. dpkg package states (non-ii states check)
8. apt dependency check (apt-get -s check)
9. snap status and list (if present)
10. flatpak status, remotes, and list (if present)
